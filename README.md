## 打字练习怎么练

每题四步：

1. **先知道用途** — 题目用日常场景命名（如「判断成绩是否及格」），一句白话说明代码能做什么。
2. **照着打** — 大字代码逐字符反馈：敲对变绿，当前位置高亮，屏幕键盘提前亮出下一个要按的键（需要 Shift 时两个键一起亮）。敲错不前进，只记错误。
3. **猜结果** — 每题一道理解题，提交后才揭晓答案；答错说明原因并允许重试。
4. **逐行看懂** — 中文解释每行在干什么、关键符号是什么意思。

进度、用时、WPM、正确率都存在浏览器 localStorage 里，关掉再开不丢。

### 两关内容

- **第 1 关 · 基础 18 题**：`print()` → 变量赋值 → 字符串 → `if/else` → 列表 → `for` 循环 → 函数，从 1 行递进到 6 行。
- **第 2 关 · 讲义原例 14 题**：对应讲义 01～12 节，最长 8 行，含 `class`、`try/except`、`assert`、列表推导式。

第 2 关保留讲义原文，代码里的中文（如 `"小林"`）显示为橙色虚线并**自动跳过**——只敲 ASCII 骨架，这样示例不需要改写，也符合真实写代码的输入习惯。

## 本地运行

不需要安装任何依赖，也不需要服务器：

```bash
# 直接双击 index.html，或在浏览器打开
start index.html          # Windows
open index.html           # macOS
```

也可以用任意静态服务器：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```
