## 打字练习怎么练

每题四步：

1. **先知道用途** — 题目用日常场景命名（如「判断成绩是否及格」），一句白话说明代码能做什么。
2. **照着打** — 大字代码逐字符反馈：敲对变绿，当前位置高亮，屏幕键盘提前亮出下一个要按的键（需要 Shift 时两个键一起亮）。敲错不前进，只记错误。
3. **猜结果** — 每题一道理解题，提交后才揭晓答案；答错说明原因并允许重试。
4. **逐行看懂** — 中文解释每行在干什么、关键符号是什么意思。

进度、用时、WPM、正确率都存在浏览器 localStorage 里，关掉再开不丢。

### 两关内容

- **第 1 关 · 基础 18 题**：`print()` → 变量赋值 → 字符串 → `if/else` → 列表 → `for` 循环 → 函数，从 1 行递进到 6 行。
- **第 2 关 · 讲义原例 14 题**：对应讲义 01～12 节，最长 8 行，含 `class`、`try/except`、`assert`、列表推导式。

第 2 关保留讲义原文，代码里的中文（如 `"小林"`）显示为橙色虚线并**自动跳过**——只敲 ASCII 骨架，这样示例不需要改写，也符合真实写代码的输入习惯。

## 真的能跑：▶ 运行按钮

两大运行入口（基于 Pyodide，浏览器里跑的是**真实 CPython**，不是模拟器）：

| 位置 | 说明 |
| --- | --- |
| 教程首页 · 章节示例 | 12 个章节示例代码块右上角有「▶ 运行」，只读执行 |
| 教程首页 · 第 4 步「改一点试试」 | 24 个可编辑运行器，改完代码点运行，验证自己想的对不对 |
| 打字练习页 · 「自己跑一遍」 | 每题理解通过后出现，预填本题代码，可以随便改数字看输出 |

- 运行环境放在 CDN，仓库体积不变；**只有第一次点「运行」时才下载**约 6–10 MB（5–10 秒，之后浏览器缓存）。
- 代码跑超过 10 秒会被强制停下（防死循环卡死页面），停完可以直接再改再跑。
- `input()` 在网页里没法真的等你敲字，会给出提示让你换成固定值。
- 报错只保留和你代码相关的部分，Pyodide 内部帧不会吓人。
- 教程首页练习题的第 2 步代码块**故意不加**运行按钮——先自己猜，别提前剧透。

## 本地运行

不需要安装任何依赖，也不需要服务器：

```bash
# 直接双击 index.html，或在浏览器打开
start index.html          # Windows
open index.html           # macOS
```

也可以用任意静态服务器：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```
